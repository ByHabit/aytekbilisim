Panele bağlanın

Değişiklikler sitenin GitHub deposuna yazılır; site yaklaşık bir dakika içinde güncellenir. Erişim anahtarı yalnızca bu tarayıcıda saklanır.

Erişim anahtarı nasıl oluşturulur?
  1. GitHub'da sağ üstteki profil resmi › Settings › en altta Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Ad verin (örneğin "Site paneli"), süre seçin (örneğin 1 yıl).
  3. Repository access: Only select repositories › yalnızca site deposunu seçin.
  4. Permissions › Repository permissions › Contents: Read and write.
  5. Generate token deyin, çıkan anahtarı kopyalayıp buraya yapıştırın. Anahtar bir daha gösterilmez; kaybederseniz yenisini oluşturun.
